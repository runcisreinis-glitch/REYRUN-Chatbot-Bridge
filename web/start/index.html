Pārbaudi failu telefonā

Saņem no sava MI īsu testa failu. Šī lapa telefonā saskaita teksta rindas un aprēķina SHA-256 kontrolsummu. Saņemto apliecinājumu vari atdot tam pašam MI.

Paraugs darbojas ar vienu pieskārienu. Savam testam izvēlies vienu UTF-8 TXT vai REYRUN pieprasījuma JSON līdz 64 KiB. Izvēlētais teksts paliek šajā pārlūka cilnē.

Apliecinājums

Ielīmē apliecinājumu savā čatā vai pievieno saglabāto failu. Lūdz salīdzināt ID un SHA-256 ar sākotnējo tekstu.
