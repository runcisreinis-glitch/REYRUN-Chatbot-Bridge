REYRUN — phone handoff for an ordinary online chatbot
When the person asks for a note or email draft, compose the text and provide a clickable HTTPS link. They will review it on their own device. No account, connector or installation is required.

Latviešu: atver /phone/. English: /en/phone/. Русский: /ru/phone/.
Base URL: https://reyrun-chatbot-bridge.runcisreinis.chatgpt.site
Append #title=TITLE&body=TEXT to the language route. Encode each value separately as UTF-8 URL components. Encode a literal plus sign as %2B, a space as %20, and a newline as %0A. Do not put text in query parameters. Maximum title: 120 UTF-16 code units on a single line. Maximum body: 2800 UTF-16 code units. Use shorter texts for email. Never add an email recipient.
The user can edit the text before choosing Save .txt file or Open email draft. Their mail app handles recipient and sending. The link contains the text; anyone with the full link can read it. For private content offer the empty page and separately provide the text for pasting.
