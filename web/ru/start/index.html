Проверьте файл на телефоне

Получите небольшой тестовый файл от своего ИИ. Эта страница на телефоне посчитает строки и вычислит контрольную сумму SHA-256. Результат можно вернуть в тот же чат.

Для примера достаточно одного нажатия. Для своего теста выберите один файл TXT в UTF-8 или JSON с запросом REYRUN размером до 64 КиБ. Выбранный текст остаётся в этой вкладке.

Результат проверки

Вставьте результат в чат или приложите сохранённый файл. Попросите ИИ сравнить ID и SHA-256 с исходным текстом.
